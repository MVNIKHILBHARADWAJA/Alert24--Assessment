# Alert24 Assessment

This project is a frontend checkout page built as part of the Alert24 Safety Systems internship assignment.

The application allows users to add traveller details, select a travel date, apply coupon codes, and view a dynamic price summary.

## Tech Stack
- React
- Vite
- Tailwind CSS
- JavaScript

## Features
- Add multiple travellers (minimum one traveller required)
- Input validation for traveller details
- Simulated thumbprint capture
- Travel date selection with past dates disabled
- Dynamic pricing calculation
- GST calculation (18% on ticket price)
- Coupon support (NEW10, NEW20)
- Responsive layout

## Pricing Rules
- Ticket price: ₹1000 per traveller
- Life jacket price: ₹100 per traveller
- GST: 18% on ticket total

## Coupon Rules
- NEW10: ₹100 discount for minimum 2 travellers
- NEW20: ₹200 discount for minimum 4 travellers
